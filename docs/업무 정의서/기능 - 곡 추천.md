# 기능 - 곡 추천

## 목적

유일하게 푸시 알림이 허용되는 상호작용. "너 들으라고 고른 곡"이라는 직접적 신호.

## 사용자 시나리오

1. 피드의 곡 카드에서 (또는 검색으로) "친구에게 추천"을 누른다.
2. 방 멤버 중 받을 사람을 고르고, 한 줄 코멘트를 붙인다.
3. 받은 사람에게 푸시 알림이 간다 — **직접 추천받았을 때만 알림** (기본 알림 OFF 원칙의 유일한 예외).
4. 받은 사람은 "내 플랫폼으로 열기"로 바로 들을 수 있다.

## 요구사항

- [ ] 곡 추천 보내기 (수신자 + 코멘트)
- [ ] 수신자에게 Expo Push 알림
- [ ] 추천함 (받은 추천 목록, 읽음 처리)
- [ ] MVP 이후: 추천곡을 친구가 실제로 들었을 때 보낸 사람에게 알림 (리텐션 훅)
