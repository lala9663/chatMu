# 기능 - 반응과 채팅

## 목적

"잡담의 소재로서의 음악"을 실현하는 상호작용. 10초 안에 끝나는 저마찰 상호작용이어야 한다.

## 사용자 시나리오

1. 친구의 곡 카드에 이모지 반응을 남긴다 (탭 한 번).
2. 곡 카드에 한 줄 채팅을 남긴다 ("이거 완전 네 스타일이잖아").
3. 반응/채팅은 방 멤버 모두에게 Realtime으로 보인다.

## 요구사항

- [ ] 곡(재생 이벤트)에 이모지 반응 — 토글 방식
- [ ] 곡에 한 줄 채팅
- [ ] Realtime 반영
- [ ] 알림은 기본 OFF (조용한 존재감 원칙)

## 정책

- 반응/채팅은 특정 재생 이벤트(`plays`)에 귀속된다. 곡 자체가 아니라 "그때 그 사람이 들은 그 곡"에 남기는 것.
- 채팅은 스레드/답글 없이 flat. 잡담이지 협업 툴이 아니다.
