# 기능 - 실시간 재생 피드

## 목적

제품의 핵심 화면. 방 멤버들이 "지금 듣는 중"인 곡을 앰비언트하게 보여준다.

## 사용자 시나리오

1. 방에 들어가면 멤버별 현재 재생 곡이 카드로 보인다 — 앨범아트 + 곡명 + 아티스트.
2. 곡 카드의 "내 플랫폼으로 열기"를 누르면 자기가 쓰는 음악 앱(멜론/스포티파이/유튜브뮤직/애플뮤직)으로 해당 곡이 열린다.
3. 멤버의 곡이 바뀌면 Realtime으로 자동 갱신된다.

## 재생 감지 경로

| 경로 | 담당 | 비고 |
|---|---|---|
| Spotify | 폴링 워커 (30초~1분 주기) | 서버에서 DB write → Realtime 푸시 |
| Android 음악앱 전체 | Kotlin 알림 리스너 모듈 | 설정 화면 권한 필요 → 온보딩 안내 공들일 것 |
| iOS Apple Music | Swift 네이티브 모듈 | 완전 실시간 아님 → "마지막 감지 시각" 표시 |

## 곡 통합 (플랫폼 간 매칭)

- 플랫폼마다 곡 ID가 다르므로 **Odesli(song.link) API**로 매칭하고 전 플랫폼 링크로 변환한다.
- 결과는 반드시 `tracks`에 캐싱 (무료 티어 rate limit). 캐시 히트 우선, 미스일 때만 호출.
- Odesli 실패 시 원본 플랫폼 링크만이라도 표시 (graceful degradation).
