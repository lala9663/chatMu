# 기능 - 잠수 모드

## 목적

**부가기능이 아니라 신뢰의 기본.** 상시 공유 서비스는 "언제든 끌 수 있다"는 확신이 없으면 3주는커녕 3일도 못 간다.

## 사용자 시나리오

1. 잠수 모드를 켜면 그 즉시 내 재생 정보가 친구들에게 공유되지 않는다.
2. 잠수 중 재생 이력은 **수집 자체를 하지 않는다** (숨기는 게 아니라 안 쌓는다).
3. 이미 피드에 올라간 특정 곡을 개별적으로 숨길 수 있다 (곡 숨기기).

## 요구사항

- [ ] 잠수 모드 ON/OFF 토글 (`users.is_sharing`)
- [ ] 시간 지정 잠수 (`sharing_paused_until`) — "1시간만 잠수"
- [ ] 곡 숨기기 — 이미 기록된 `plays` 개별 숨김
- [ ] 워커와 모든 감지 모듈(Kotlin/Swift)이 이 플래그를 존중해야 함

## 크리티컬 규칙

> [!danger] 공유 OFF 상태에서 데이터가 새는 버그는 크리티컬로 취급한다.

- 감지 경로가 3개(워커/Android/iOS)이므로 **각 경로마다** 잠수 플래그 체크가 있어야 한다.
- 클라이언트 필터링이 아니라 **write 자체를 차단**하는 방향으로 구현한다 (워커는 폴링 전 체크, 네이티브 모듈은 업로드 전 체크, DB는 RLS/트리거로 이중 방어).
