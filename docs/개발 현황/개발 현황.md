## 리스크 / 이슈

| 항목 | 상태 | 메모 |
|---|---|---|
| Spotify API 정책 변경 | 감수 | 구조적 리스크로 확정 |
| **Spotify Web API = 앱 소유자 Premium 필수 (2025 정책)** | **블로킹** | 무료 계정으로는 currently-playing 403. 연동/토큰 흐름은 정상 동작 확인(2026-07-08). 해소: Premium 구독 또는 Premium 계정으로 개발자 앱 재생성. 대안: Android 알림 리스너는 Spotify 포함 전 음악앱을 로컬 감지하므로 이 제약과 무관 |
| iPhone + 멜론/유튜브뮤직 감지 불가 | 스코프 아웃 | 추후 공유 시트 확장 고려 |
| Odesli rate limit | 대응 설계됨 | 캐시 우선 + graceful degradation |
