# 기능 - 방 생성과 초대

## 목적

친구 그룹 하나가 모이는 공간. 방이 없으면 제품이 성립하지 않는다.

## 사용자 시나리오

1. 사용자가 카카오 로그인 후 방을 생성한다.
2. 생성 시 6자리 방 코드가 발급된다.
3. 친구는 방 코드를 입력해 입장한다. (MVP: 코드 입장, 딥링크는 뼈대만)
4. 카카오 메시지 공유로 초대 링크를 보낼 수 있다.

## 요구사항

- [ ] 카카오 OAuth 로그인 (Supabase Auth 연동)
- [ ] 방 생성 — 이름, 방 코드 자동 발급
- [ ] 방 코드로 입장
- [ ] 방 멤버 목록 조회
- [ ] 카카오 초대 메시지 공유 (딥링크 뼈대)

## 정책

- 한 유저가 여러 방에 속할 수 있다.
- 방 데이터는 RLS로 **멤버만 read** 가능.
